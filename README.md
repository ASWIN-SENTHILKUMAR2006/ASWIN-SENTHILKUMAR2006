### Work

#### EKART — e-commerce backend &nbsp;·&nbsp; [repository →](https://github.com/ASWIN-SENTHILKUMAR2006/E-Kart-SpringBoot)

`Java` `Spring Boot` `Spring MVC` `Spring Data JPA` `MySQL` `Maven` &nbsp;·&nbsp; **in progress**

The project I use to answer "can you build a real backend, not a CRUD demo?"

- **What it is** — an e-commerce backend with product management, cart handling and order processing as separate, properly bounded modules.
- **How it's built** — layered Controller → Service → Repository architecture, Spring Data JPA entity relationships, MySQL persistence, REST endpoints.
- **Why it matters to me** — modelling real business workflows, where the interesting problems are ordering, state and relationships rather than endpoints.

#### ADR Prediction — the research behind the patent &nbsp;·&nbsp; [repository →](https://github.com/ASWIN-SENTHILKUMAR2006/Adverse-Drug-Reaction---Development)

`Python` `NLP` `NER` `XGBoost`

A multimodal system that predicts adverse drug reactions from two very different inputs at once: structured patient and drug data, and free clinical text. Text runs through tokenisation, lemmatisation and named entity recognition; the fused features go to an XGBoost classifier that returns an ADR probability and a risk classification, with the detected drug and symptom entities surfaced alongside it. Usable through a web interface for single predictions or CSV batch upload.

#### DevSecOps pipeline for automated vulnerability mitigation

`GitHub Actions` `SonarCloud (SAST)` `Snyk (SCA)`

Security moved out of the release bottleneck and into the commit. Static analysis and dependency auditing run on every push, insecure builds are blocked before deployment, and SQL injection risks and vulnerable libraries surface in real time instead of at review.
